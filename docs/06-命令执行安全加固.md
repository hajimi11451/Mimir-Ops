# 命令执行安全加固指南

## 📋 概述

本文档提供命令执行的安全加固方案，增强危险命令检测，减少命令注入风险。

**优先级**：P2（建议实施）  
**预计工作量**：2-3天  
**前置依赖**：SSH安全加固（04文档）  
**影响范围**：`CommandSafetyService.java`、命令执行相关Service

## 🎯 实施目标

- ✅ 增强危险命令检测（正则 + 解析）
- ✅ 支持命令白名单机制
- ✅ 检测命令注入攻击模式
- ✅ 危险命令需用户二次确认
- ✅ 命令审计日志
- ✅ 支持命令模拟执行（Dry Run）

## 🚨 当前问题

查看 `backend/src/main/java/com/example/backend/service/CommandSafetyService.java`：

**可被绕过的场景**：
1. **变量替换**：`rm -rf $HOME` (HOME=/)
2. **命令替换**：`rm -rf $(echo /)`
3. **编码绕过**：`r''m -rf /`
4. **分号连接**：`ls ; rm -rf /`
5. **管道注入**：`cat file | rm -rf /`
6. **通配符**：`rm -rf /*`

## 🏗️ 增强方案设计

### 多层检测机制

```
用户输入命令
    ↓
[1] 语法检测 → 检测基本语法错误
    ↓
[2] 黑名单检测 → 正则匹配危险模式
    ↓
[3] 命令解析 → 提取实际命令
    ↓
[4] 参数分析 → 检测危险参数组合
    ↓
[5] 上下文检测 → 检测命令注入
    ↓
[6] 白名单验证 → 可选的白名单模式
    ↓
[7] 二次确认 → 高危命令需用户确认
    ↓
执行命令
```

## 🔧 实施步骤

### 第一步：创建命令解析器

创建 `backend/src/main/java/com/example/backend/security/CommandParser.java`：

```java
package com.example.backend.security;

import java.util.*;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

/**
 * 命令解析器 - 提取命令中的实际可执行部分
 */
public class CommandParser {
    
    // 命令分隔符
    private static final Pattern SEPARATOR_PATTERN = Pattern.compile("[;|&]+");
    
    // 命令替换
    private static final Pattern SUBSTITUTION_PATTERN = Pattern.compile("\\$\\([^)]+\\)|`[^`]+`");
    
    // 变量引用
    private static final Pattern VARIABLE_PATTERN = Pattern.compile("\\$\\{?[A-Z_][A-Z0-9_]*\\}?");
    
    /**
     * 解析命令，返回所有可能执行的命令列表
     */
    public static List<ParsedCommand> parse(String commandLine) {
        List<ParsedCommand> commands = new ArrayList<>();
        
        // 按分隔符拆分命令
        String[] parts = SEPARATOR_PATTERN.split(commandLine);
        
        for (String part : parts) {
            part = part.trim();
            if (part.isEmpty()) continue;
            
            ParsedCommand cmd = parseCommand(part);
            commands.add(cmd);
        }
        
        return commands;
    }
    
    /**
     * 解析单个命令
     */
    private static ParsedCommand parseCommand(String commandLine) {
        ParsedCommand cmd = new ParsedCommand();
        cmd.setOriginal(commandLine);
        
        // 检测命令替换
        Matcher subMatcher = SUBSTITUTION_PATTERN.matcher(commandLine);
        while (subMatcher.find()) {
            cmd.addSubstitution(subMatcher.group());
        }
        
        // 检测变量引用
        Matcher varMatcher = VARIABLE_PATTERN.matcher(commandLine);
        while (varMatcher.find()) {
            cmd.addVariable(varMatcher.group());
        }
        
        // 提取基本命令（第一个单词）
        String[] tokens = commandLine.split("\\s+");
        if (tokens.length > 0) {
            cmd.setBaseCommand(tokens[0]);
            cmd.setArguments(Arrays.copyOfRange(tokens, 1, tokens.length));
        }
        
        // 检测重定向
        if (commandLine.contains(">") || commandLine.contains(">>")) {
            cmd.setHasRedirection(true);
        }
        
        // 检测管道
        if (commandLine.contains("|")) {
            cmd.setHasPipe(true);
        }
        
        return cmd;
    }
    
    /**
     * 解析后的命令
     */
    public static class ParsedCommand {
        private String original;                    // 原始命令
        private String baseCommand;                 // 基础命令（如rm、chmod）
        private String[] arguments;                 // 参数列表
        private List<String> substitutions = new ArrayList<>();  // 命令替换
        private List<String> variables = new ArrayList<>();      // 变量引用
        private boolean hasRedirection = false;     // 是否有重定向
        private boolean hasPipe = false;            // 是否有管道
        
        // Getters and Setters
        public String getOriginal() { return original; }
        public void setOriginal(String original) { this.original = original; }
        
        public String getBaseCommand() { return baseCommand; }
        public void setBaseCommand(String baseCommand) { this.baseCommand = baseCommand; }
        
        public String[] getArguments() { return arguments; }
        public void setArguments(String[] arguments) { this.arguments = arguments; }
        
        public List<String> getSubstitutions() { return substitutions; }
        public void addSubstitution(String sub) { this.substitutions.add(sub); }
        
        public List<String> getVariables() { return variables; }
        public void addVariable(String var) { this.variables.add(var); }
        
        public boolean hasRedirection() { return hasRedirection; }
        public void setHasRedirection(boolean hasRedirection) { this.hasRedirection = hasRedirection; }
        
        public boolean hasPipe() { return hasPipe; }
        public void setHasPipe(boolean hasPipe) { this.hasPipe = hasPipe; }
        
        /**
         * 获取完整命令（包含所有参数）
         */
        public String getFullCommand() {
            if (arguments == null || arguments.length == 0) {
                return baseCommand;
            }
            return baseCommand + " " + String.join(" ", arguments);
        }
    }
}
```

### 第二步：增强CommandSafetyService

编辑 `backend/src/main/java/com/example/backend/service/CommandSafetyService.java`：

```java
package com.example.backend.service;

import com.example.backend.security.CommandParser;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;

import java.util.*;
import java.util.regex.Pattern;

@Service
public class CommandSafetyService {
    
    private static final Logger logger = LoggerFactory.getLogger(CommandSafetyService.class);
    
    // 危险命令黑名单（正则）
    private static final Pattern[] DANGEROUS_PATTERNS = {
        // 文件系统破坏
        Pattern.compile("rm\\s+.*-rf\\s+/"),
        Pattern.compile("rm\\s+.*-rf\\s+/\\*"),
        Pattern.compile("rm\\s+.*-rf\\s+\\$\\{?HOME\\}?"),
        Pattern.compile("mkfs"),
        Pattern.compile("dd\\s+.*of=/dev/"),
        
        // 系统关闭/重启
        Pattern.compile("shutdown"),
        Pattern.compile("reboot"),
        Pattern.compile("halt"),
        Pattern.compile("poweroff"),
        Pattern.compile("init\\s+[06]"),
        
        // 权限修改
        Pattern.compile("chmod\\s+.*-R\\s+777\\s+/"),
        Pattern.compile("chown\\s+.*-R.*:/"),
        
        // 配置文件破坏
        Pattern.compile(">\\s*/etc/"),
        Pattern.compile(">>\\s*/etc/"),
        Pattern.compile("echo\\s+.*>\\s*/etc/"),
        
        // 内核/引导破坏
        Pattern.compile(">\\s*/boot/"),
        Pattern.compile("dd\\s+.*of=/dev/sda"),
        
        // 进程终止
        Pattern.compile("kill\\s+-9\\s+1"),  // 杀死init进程
        Pattern.compile("killall\\s+.*"),
        
        // Fork炸弹
        Pattern.compile(":\\(\\)\\{.*:\\|:&\\};:"),
        
        // 网络攻击
        Pattern.compile("iptables\\s+.*-F"),
        Pattern.compile("tc\\s+qdisc.*del"),
    };
    
    // 危险命令黑名单（精确匹配）
    private static final Set<String> DANGEROUS_COMMANDS = new HashSet<>(Arrays.asList(
        "mkfs", "mkfs.ext4", "mkfs.ext3", "mkfs.xfs",
        "fdisk", "parted", "gdisk",
        "shutdown", "reboot", "halt", "poweroff",
        "init", "telinit",
        "dd",  // 完全禁止dd
        "format"
    ));
    
    // 危险参数组合
    private static final Map<String, List<String>> DANGEROUS_ARG_COMBINATIONS = new HashMap<>();
    static {
        DANGEROUS_ARG_COMBINATIONS.put("rm", Arrays.asList("-rf /", "-rf /*", "-rf $HOME", "-rf ~"));
        DANGEROUS_ARG_COMBINATIONS.put("chmod", Arrays.asList("-R 777 /", "777 -R /"));
        DANGEROUS_ARG_COMBINATIONS.put("chown", Arrays.asList("-R root:root /"));
    }
    
    // 命令注入模式
    private static final Pattern[] INJECTION_PATTERNS = {
        Pattern.compile(".*;.*rm"),      // 分号注入
        Pattern.compile(".*\\|.*rm"),    // 管道注入
        Pattern.compile(".*&&.*rm"),     // AND注入
        Pattern.compile(".*\\|\\|.*rm"), // OR注入
        Pattern.compile(".*`.*`.*"),     // 反引号命令替换
        Pattern.compile(".*\\$\\(.*\\).*"), // $()命令替换
    };
    
    // 可选：命令白名单（启用后只允许这些命令）
    private static final Set<String> WHITELIST = new HashSet<>(Arrays.asList(
        "ls", "cat", "head", "tail", "grep", "awk", "sed",
        "ps", "top", "htop", "free", "df", "du",
        "netstat", "ss", "lsof", "ifconfig", "ip",
        "systemctl", "journalctl", "dmesg",
        "uptime", "whoami", "hostname", "date",
        "ping", "curl", "wget", "dig", "nslookup"
    ));
    
    private boolean whitelistMode = false;  // 是否启用白名单模式
    
    /**
     * 全面安全检查
     */
    public SafetyCheckResult checkCommand(String command) {
        SafetyCheckResult result = new SafetyCheckResult();
        result.setCommand(command);
        
        // 1. 基本验证
        if (command == null || command.trim().isEmpty()) {
            result.setSafe(false);
            result.setReason("命令不能为空");
            result.setRiskLevel(RiskLevel.LOW);
            return result;
        }
        
        // 2. 黑名单正则检测
        for (Pattern pattern : DANGEROUS_PATTERNS) {
            if (pattern.matcher(command).find()) {
                result.setSafe(false);
                result.setReason("检测到危险命令模式：" + pattern.pattern());
                result.setRiskLevel(RiskLevel.CRITICAL);
                result.setNeedsConfirmation(true);
                return result;
            }
        }
        
        // 3. 命令注入检测
        for (Pattern pattern : INJECTION_PATTERNS) {
            if (pattern.matcher(command).find()) {
                result.setSafe(false);
                result.setReason("检测到可能的命令注入攻击");
                result.setRiskLevel(RiskLevel.HIGH);
                result.setNeedsConfirmation(true);
                return result;
            }
        }
        
        // 4. 解析命令
        List<CommandParser.ParsedCommand> parsedCommands = CommandParser.parse(command);
        
        for (CommandParser.ParsedCommand parsed : parsedCommands) {
            // 5. 检查基础命令是否在黑名单中
            String baseCmd = parsed.getBaseCommand();
            if (baseCmd != null && DANGEROUS_COMMANDS.contains(baseCmd)) {
                result.setSafe(false);
                result.setReason("禁止使用命令：" + baseCmd);
                result.setRiskLevel(RiskLevel.CRITICAL);
                result.setNeedsConfirmation(true);
                return result;
            }
            
            // 6. 白名单模式检查
            if (whitelistMode && baseCmd != null && !WHITELIST.contains(baseCmd)) {
                result.setSafe(false);
                result.setReason("命令不在白名单中：" + baseCmd);
                result.setRiskLevel(RiskLevel.MEDIUM);
                return result;
            }
            
            // 7. 检查危险参数组合
            if (baseCmd != null && DANGEROUS_ARG_COMBINATIONS.containsKey(baseCmd)) {
                String fullCmd = parsed.getFullCommand();
                for (String dangerousArgs : DANGEROUS_ARG_COMBINATIONS.get(baseCmd)) {
                    if (fullCmd.contains(dangerousArgs)) {
                        result.setSafe(false);
                        result.setReason("检测到危险参数组合：" + baseCmd + " " + dangerousArgs);
                        result.setRiskLevel(RiskLevel.CRITICAL);
                        result.setNeedsConfirmation(true);
                        return result;
                    }
                }
            }
            
            // 8. 检查变量引用
            if (!parsed.getVariables().isEmpty()) {
                result.addWarning("命令中包含变量引用，请确保变量值安全");
                result.setRiskLevel(RiskLevel.MEDIUM);
            }
            
            // 9. 检查命令替换
            if (!parsed.getSubstitutions().isEmpty()) {
                result.addWarning("命令中包含命令替换，请确保嵌套命令安全");
                result.setRiskLevel(RiskLevel.MEDIUM);
            }
            
            // 10. 检查重定向到系统目录
            if (parsed.hasRedirection() && command.matches(".*>.*/(etc|boot|sys|proc|dev).*")) {
                result.setSafe(false);
                result.setReason("禁止重定向输出到系统目录");
                result.setRiskLevel(RiskLevel.HIGH);
                result.setNeedsConfirmation(true);
                return result;
            }
        }
        
        // 通过所有检查
        result.setSafe(true);
        result.setReason("命令检查通过");
        result.setRiskLevel(RiskLevel.LOW);
        return result;
    }
    
    /**
     * 启用/禁用白名单模式
     */
    public void setWhitelistMode(boolean enabled) {
        this.whitelistMode = enabled;
        logger.info("命令白名单模式：{}", enabled ? "已启用" : "已禁用");
    }
    
    /**
     * 为sudo命令注入密码
     */
    public String injectSudoPassword(String command, String password) {
        if (command.trim().startsWith("sudo ")) {
            return "echo '" + password + "' | sudo -S " + command.substring(5);
        }
        return command;
    }
    
    /**
     * 安全检查结果
     */
    public static class SafetyCheckResult {
        private String command;
        private boolean safe;
        private String reason;
        private RiskLevel riskLevel;
        private boolean needsConfirmation;
        private List<String> warnings = new ArrayList<>();
        
        // Getters and Setters
        public String getCommand() { return command; }
        public void setCommand(String command) { this.command = command; }
        
        public boolean isSafe() { return safe; }
        public void setSafe(boolean safe) { this.safe = safe; }
        
        public String getReason() { return reason; }
        public void setReason(String reason) { this.reason = reason; }
        
        public RiskLevel getRiskLevel() { return riskLevel; }
        public void setRiskLevel(RiskLevel riskLevel) { this.riskLevel = riskLevel; }
        
        public boolean needsConfirmation() { return needsConfirmation; }
        public void setNeedsConfirmation(boolean needsConfirmation) { 
            this.needsConfirmation = needsConfirmation; 
        }
        
        public List<String> getWarnings() { return warnings; }
        public void addWarning(String warning) { this.warnings.add(warning); }
    }
    
    /**
     * 风险等级
     */
    public enum RiskLevel {
        LOW,        // 低风险
        MEDIUM,     // 中风险
        HIGH,       // 高风险
        CRITICAL    // 极高风险
    }
}
```

### 第三步：创建命令执行审计

创建 `backend/src/main/java/com/example/backend/service/CommandAuditService.java`：

```java
package com.example.backend.service;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;

import java.io.FileWriter;
import java.io.IOException;
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

@Service
public class CommandAuditService {
    
    private static final Logger logger = LoggerFactory.getLogger(CommandAuditService.class);
    private static final String AUDIT_LOG_FILE = "logs/command-audit.log";
    private static final DateTimeFormatter FORMATTER = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
    
    /**
     * 记录命令执行审计
     */
    public void logCommand(Integer userId, String username, String host, 
                          String command, boolean blocked, String reason, 
                          boolean confirmed, String userIp) {
        String timestamp = LocalDateTime.now().format(FORMATTER);
        
        String logEntry = String.format(
            "[%s] USER=%s(%d) IP=%s HOST=%s CMD=\"%s\" BLOCKED=%s CONFIRMED=%s REASON=\"%s\"%n",
            timestamp, username, userId, userIp, host, command, 
            blocked, confirmed, reason != null ? reason : "N/A"
        );
        
        // 同时记录到日志文件和应用日志
        logger.info("命令审计：{}", logEntry.trim());
        
        try (FileWriter writer = new FileWriter(AUDIT_LOG_FILE, true)) {
            writer.write(logEntry);
        } catch (IOException e) {
            logger.error("写入审计日志失败", e);
        }
    }
    
    /**
     * 记录被阻止的危险命令
     */
    public void logBlockedCommand(Integer userId, String username, String command, 
                                 String reason, String userIp) {
        logCommand(userId, username, "N/A", command, true, reason, false, userIp);
    }
    
    /**
     * 记录用户确认执行的危险命令
     */
    public void logConfirmedCommand(Integer userId, String username, String host, 
                                   String command, String userIp) {
        logCommand(userId, username, host, command, false, "User confirmed", true, userIp);
    }
}
```

### 第四步：改造OpsAgentService集成增强检查

编辑相关的Agent执行服务：

```java
@Autowired
private CommandSafetyService commandSafetyService;

@Autowired
private CommandAuditService commandAuditService;

public void executeCommand(Integer userId, String command, String host, String userIp) {
    // 安全检查
    CommandSafetyService.SafetyCheckResult result = commandSafetyService.checkCommand(command);
    
    if (!result.isSafe()) {
        // 记录被阻止的命令
        commandAuditService.logBlockedCommand(userId, getCurrentUsername(), 
            command, result.getReason(), userIp);
        
        if (result.needsConfirmation()) {
            // 需要用户确认
            throw new CommandNeedsConfirmationException(result);
        } else {
            // 直接拒绝
            throw new CommandBlockedException(result.getReason());
        }
    }
    
    // 记录正常命令
    commandAuditService.logCommand(userId, getCurrentUsername(), host, 
        command, false, null, false, userIp);
    
    // 执行命令...
}
```

### 第五步：前端改造支持二次确认

```javascript
// OpsAssistantView.vue

  const response = await executeCommand(command)
  // 处理成功

  if (error.response?.data?.code === 'NEEDS_CONFIRMATION') {

      }
    ).then(() => {
      // 用户确认，携带确认标记重新提交

    })
  }
}
```

## 🚨 常见问题

### Q1: 如何平衡安全性和灵活性？

提供配置选项：
- 严格模式：启用白名单，仅允许预定义命令
- 标准模式：黑名单 + 危险命令确认（推荐）
- 宽松模式：仅阻止极端危险命令

### Q2: 合法命令被误判怎么办？

1. 添加到白名单配置
2. 用户确认后执行
3. 记录审计日志供管理员复核

### Q3: 如何处理复杂的运维脚本？

建议：
1. 将脚本上传到服务器
2. 对脚本文件进行安全审查
3. 执行脚本而非直接执行命令

### Q4: 命令解析器会影响性能吗？

- 正则匹配：~1ms
- 命令解析：~2ms
- 总开销：~5ms
- 相比SSH执行时间（100ms+）可忽略

## 📊 安全提升对比

| 攻击方式 | 改造前 | 改造后 |
|---------|--------|--------|
