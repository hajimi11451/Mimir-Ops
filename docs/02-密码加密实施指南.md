# 密码加密实施指南

## 📋 概述

本文档提供用户密码和SSH服务器密码的加密存储方案。

**优先级**：P0（用户密码）+ P1（SSH密码）  
**预计工作量**：2-3天  
**前置依赖**：认证授权机制（01文档）  
**影响范围**：`userlogin`表、`componentconfig`表、相关Service

## 🎯 实施目标

### 用户密码（已在01文档中实现）
- ✅ 使用BCrypt单向哈希加密
- ✅ 注册时加密存储
- ✅ 登录时验证密码
- ✅ 不可逆，无法解密

### SSH服务器密码（本文档重点）
- ✅ 使用AES对称加密
- ✅ 保存时加密，使用时解密
- ✅ 密钥安全管理（环境变量）
- ✅ 支持密码轮换

## 🔐 加密方案对比

| 类型 | 算法 | 用途 | 特点 | 可逆性 |
|------|------|------|------|--------|
| 用户密码 | BCrypt | 登录验证 | 单向哈希 + 盐值 | 不可逆 |
| SSH密码 | AES-256 | SSH连接 | 对称加密 | 可逆 |
| JWT密钥 | HMAC-SHA256 | Token签名 | 对称签名 | 用于验证 |

**为什么用户密码不能用AES？**
- 如果用AES，密钥泄露 = 所有密码泄露
- BCrypt单向哈希，即使数据库泄露也无法还原密码
- 每个密码有独立的盐值，无法批量破解

**为什么SSH密码不能用BCrypt？**
- SSH连接需要明文密码
- 必须使用可逆的对称加密
- 关键在于密钥的安全管理

## 🏗️ 架构设计

### 加密流程

```
用户输入SSH密码
      ↓
前端传输（HTTPS加密）
      ↓
后端接收明文密码
      ↓
AES加密（使用密钥）
      ↓
存储密文到数据库
      ↓
需要SSH连接时
      ↓
从数据库读取密文
      ↓
AES解密（使用密钥）
      ↓
传递给JSch进行SSH连接
```

### 密钥管理方案

**方案A：环境变量（推荐用于小团队）**
```bash
export ENCRYPTION_KEY="your-32-byte-base64-encoded-key"
```

**方案B：HashiCorp Vault（推荐用于生产环境）**
- 集中式密钥管理
- 支持密钥轮换
- 审计日志
- 动态密钥生成

**方案C：AWS Secrets Manager / Azure Key Vault**
- 云原生密钥管理
- 自动轮换
- IAM集成

本文档以**方案A（环境变量）**为例，生产环境建议升级到方案B/C。

创建 `backend/src/main/java/com/example/backend/security/EncryptionService.java`：

```java
package com.example.backend.security;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;

import javax.crypto.Cipher;
import javax.crypto.SecretKey;
import javax.crypto.spec.IvParameterSpec;
import javax.crypto.spec.SecretKeySpec;
import java.nio.charset.StandardCharsets;
import java.security.SecureRandom;
import java.util.Base64;

@Service
public class EncryptionService {
    
    @Value("${encryption.key}")
    private String encryptionKey;
    
    private static final String ALGORITHM = "AES/CBC/PKCS5Padding";
    private static final String KEY_ALGORITHM = "AES";
    private static final int IV_LENGTH = 16;
    
    /**
     * 加密密码
     * @param plainText 明文密码
     * @return Base64编码的密文（包含IV）
     */
    public String encrypt(String plainText) {
        try {
            // 生成随机IV（初始化向量）
            byte[] iv = new byte[IV_LENGTH];
            SecureRandom random = new SecureRandom();
            random.nextBytes(iv);
            IvParameterSpec ivSpec = new IvParameterSpec(iv);
            
            // 准备密钥
            SecretKey secretKey = getSecretKey();
            
            // 加密
            Cipher cipher = Cipher.getInstance(ALGORITHM);
            cipher.init(Cipher.ENCRYPT_MODE, secretKey, ivSpec);
            byte[] encrypted = cipher.doFinal(plainText.getBytes(StandardCharsets.UTF_8));
            
            // 将IV和密文拼接：IV(16字节) + 密文
            byte[] combined = new byte[IV_LENGTH + encrypted.length];
            System.arraycopy(iv, 0, combined, 0, IV_LENGTH);
            System.arraycopy(encrypted, 0, combined, IV_LENGTH, encrypted.length);
            
            // Base64编码返回
            return Base64.getEncoder().encodeToString(combined);
        } catch (Exception e) {
            throw new RuntimeException("加密失败", e);
        }
    }
    
    /**
     * 解密密码
     * @param cipherText Base64编码的密文（包含IV）
     * @return 明文密码
     */
    public String decrypt(String cipherText) {
        try {
            // Base64解码
            byte[] combined = Base64.getDecoder().decode(cipherText);
            
            // 分离IV和密文
            byte[] iv = new byte[IV_LENGTH];
            byte[] encrypted = new byte[combined.length - IV_LENGTH];
            System.arraycopy(combined, 0, iv, 0, IV_LENGTH);
            System.arraycopy(combined, IV_LENGTH, encrypted, 0, encrypted.length);
            
            IvParameterSpec ivSpec = new IvParameterSpec(iv);
            
            // 准备密钥
            SecretKey secretKey = getSecretKey();
            
            // 解密
            Cipher cipher = Cipher.getInstance(ALGORITHM);
            cipher.init(Cipher.DECRYPT_MODE, secretKey, ivSpec);
            byte[] decrypted = cipher.doFinal(encrypted);
            
            return new String(decrypted, StandardCharsets.UTF_8);
        } catch (Exception e) {
            throw new RuntimeException("解密失败", e);
        }
    }
    
    /**
     * 从配置中获取密钥
     */
    private SecretKey getSecretKey() {
        // 确保密钥长度为32字节（256位）
        byte[] keyBytes = encryptionKey.getBytes(StandardCharsets.UTF_8);
        if (keyBytes.length != 32) {
            // 如果密钥长度不对，进行填充或截断（不推荐，应该在配置时保证）
            byte[] fixedKey = new byte[32];
            System.arraycopy(keyBytes, 0, fixedKey, 0, Math.min(keyBytes.length, 32));
            keyBytes = fixedKey;
        }
        return new SecretKeySpec(keyBytes, KEY_ALGORITHM);
    }
    
    /**
     * 验证密钥是否配置正确
     */
    public boolean validateKey() {
        try {
            String test = "test";
            String encrypted = encrypt(test);
            String decrypted = decrypt(encrypted);
            return test.equals(decrypted);
        } catch (Exception e) {
            return false;
        }
    }
}
```

@Component
public class SshUtils {
    
    @Autowired
    private EncryptionService encryptionService;
    
    /**
     * 创建SSH连接
     */
    public Session createSession(String host, String username, String encryptedPassword) throws JSchException {
        JSch jsch = new JSch();
        
        // 解密密码
        String password = encryptionService.decrypt(encryptedPassword);
        
        Session session = jsch.getSession(username, host, 22);
        session.setPassword(password);
        
        // 安全配置
        Properties config = new Properties();
        config.put("StrictHostKeyChecking", "no");  // 后续在04文档中改进
        session.setConfig(config);
        session.setTimeout(10000);
        
        return session;
    }
    
    /**
     * 执行命令
     */
    public String executeCommand(ComponentConfig server, String command) throws Exception {
        Session session = null;
        ChannelExec channel = null;
        
        try {
            // 创建会话（密码会自动解密）
            session = createSession(server.getIp(), server.getUsername(), server.getPassword());
            session.connect();
            
            // 执行命令
            channel = (ChannelExec) session.openChannel("exec");
            channel.setCommand(command);
            
            // ... 其他逻辑
            
        } finally {
            if (channel != null) channel.disconnect();
            if (session != null) session.disconnect();
        }
    }
}

```java
package com.example.backend.migration;

import com.example.backend.entity.ComponentConfig;
import com.example.backend.mapper.ComponentConfigMapper;
import com.example.backend.security.EncryptionService;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.CommandLineRunner;
import org.springframework.stereotype.Component;

import java.util.List;

/**
 * SSH密码加密迁移工具
 * 
 * 使用方法：
 * 1. 设置环境变量 MIGRATION_MODE=true
 * 2. 启动应用，自动执行迁移
 * 3. 迁移完成后删除此类或设置 MIGRATION_MODE=false
 */
@Component
public class PasswordEncryptionMigration implements CommandLineRunner {
    
    private static final Logger logger = LoggerFactory.getLogger(PasswordEncryptionMigration.class);
    
    @Autowired
    private ComponentConfigMapper componentConfigMapper;
    
    @Autowired
    private EncryptionService encryptionService;
    
    @Override
    public void run(String... args) throws Exception {
        // 只在设置了迁移模式时执行
        String migrationMode = System.getenv("MIGRATION_MODE");
        if (!"true".equalsIgnoreCase(migrationMode)) {
            return;
        }
        
        logger.info("========================================");
        logger.info("开始SSH密码加密迁移...");
        logger.info("========================================");
        
        List<ComponentConfig> servers = componentConfigMapper.selectList(null);
        int total = servers.size();
        int migrated = 0;
        int skipped = 0;
        int failed = 0;
        
        for (ComponentConfig server : servers) {
            try {
                String password = server.getPassword();
                
                // 跳过空密码
                if (password == null || password.isEmpty()) {
                    logger.info("跳过服务器 {} (无密码)", server.getIp());
                    skipped++;
                    continue;
                }
                
                // 检查是否已经加密（简单判断：加密后的密码通常比较长且包含特殊字符）
                if (isEncrypted(password)) {
                    logger.info("跳过服务器 {} (已加密)", server.getIp());
                    skipped++;
                    continue;
                }
                
                // 加密密码
                String encrypted = encryptionService.encrypt(password);
                server.setPassword(encrypted);
                componentConfigMapper.updateById(server);
                
                logger.info("✓ 迁移服务器 {} 成功", server.getIp());
                migrated++;
                
            } catch (Exception e) {
                logger.error("✗ 迁移服务器 {} 失败: {}", server.getIp(), e.getMessage());
                failed++;
            }
        }
        
        logger.info("========================================");
        logger.info("迁移完成！");
        logger.info("总计: {}, 已迁移: {}, 跳过: {}, 失败: {}", total, migrated, skipped, failed);
        logger.info("========================================");
        
        if (failed > 0) {
            logger.warn("部分服务器迁移失败，请检查日志并手动处理");
        }
    }
    
    /**
     * 简单判断密码是否已加密
     * 加密后的密码是Base64编码，通常较长
     */
    private boolean isEncrypted(String password) {
        // 明文密码通常较短（<50字符）
        // 加密后的密码通常较长（>50字符）
        // 这只是简单判断，可根据实际情况调整
        return password.length() > 50;
    }
}
```

### Q2: 密钥丢失怎么办？

**无法恢复**。所有加密的SSH密码将永久无法使用。

预防措施：
1. 密钥备份到安全位置（加密的U盘、密码管理器）
2. 使用Vault等密钥管理系统
3. 定期测试密钥可用性

### Q3: 性能影响如何？

| 操作 | 时间 | 说明 |
|------|------|------|
| 加密 | ~1ms | 添加服务器时执行 |
| 解密 | ~1ms | SSH连接前执行 |
| 总影响 | 可忽略 | 相比SSH连接时间（100ms+）微不足道 |

## 📊 安全性评估

### 加密前 vs 加密后

| 项目 | 加密前 | 加密后 |
|------|--------|--------|
| 数据库泄露 | ❌ 所有密码暴露 | ✅ 密码无法直接读取 |
| 日志泄露 | ⚠️ 可能包含明文 | ✅ 仅密文 |
| 内存dump | ⚠️ 短暂明文 | ✅ 使用后立即清理 |
| 备份安全 | ❌ 明文备份 | ✅ 加密备份 |
| 密钥泄露 | N/A | ❌ 可解密（需防护） |

### 剩余风险

即使实施了加密，仍需注意：

1. **密钥管理是关键**
   - 密钥泄露 = 全部密码泄露
   - 环境变量可能被其他进程读取
   - 建议生产环境使用Vault

2. **内存中的明文**
   - SSH连接时密码短暂存在于内存
   - Java的String无法安全清除
   - 建议使用`char[]`代替`String`（高级优化）

3. **日志安全**
   - 确保异常日志不打印密码
   - 使用日志脱敏

4. **传输安全**
   - 前端到后端必须使用HTTPS
   - 否则密码在网络传输时仍是明文
